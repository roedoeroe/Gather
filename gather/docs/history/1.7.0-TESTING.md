## Important exercised behavior

The real rendered journey creates Northbridge/October review and Alex Example, launches a search through the actual workspace module, supplies a controlled browser opener relationship, and starts the actual capture controller. While the captured viewport awaits rectangle selection, it switches the global workspace to Southridge. The saved image remains under Northbridge/Alex and retains its originating search reference.

It verifies same-name subject captures use different folders, subject rename retains history, full-page canvas stitching retains original tiles and trims bottom overlap, and cancellation restores actual source-page scroll and temporary sticky styles. A pixel assertion proves opaque redaction, and hashes prove the original image bytes stayed unchanged. A denied Downloads double followed by Retry retains the stored image.

Binary backup tests verify remapping into existing work, exact restore into separate empty browser-origin storage, original/derivative and subject/search relationships, corruption rejection before mutation, aborted IndexedDB transaction rollback, protected active jobs, interrupted-job recovery, one-time restore-journal replay, missing-asset errors, restart/reload persistence and selected-scan report isolation.

The canvas screenshots are obtained through a test double backed by Playwright screenshots of a real rendered fictional page. This exercises the actual acquisition/stitching/controller code but does **not** verify native `captureVisibleTab` grant or focus behavior. Similarly, the exporter runs real application code against a controlled Downloads API; it does not prove successful OS folder writes.

## Reproduce

From the development package root, with Node 24 and Python 3:

```sh
node --test tests/*.test.mjs
python3 scripts/package.py
```

Browser tests use Playwright 1.62.1 and Chromium 151 here. If Playwright is not already provided by your runner, install it separately without changing extension runtime dependencies:

```sh
npm install --prefix .tools --no-save --package-lock=false playwright@1.62.1
NODE_PATH="$PWD/.tools/node_modules" GATHER_CHROMIUM_PATH=/path/to/chromium node tests/browser-capture.mjs
```

Use a browser with a working security sandbox. In this cloud runner, the filesystem sandbox presents incorrect ownership for the Chrome setuid helper and prevents user namespace setup. Approved execution outside that tool sandbox restores correct ownership/namespaces while **keeping `chromiumSandbox:true`**. Do not solve launch errors with `--no-sandbox`, disabled TLS verification or policy changes.

`tests/browser-capture.mjs` starts a temporary internal HTTP fixture server and cleans its browser profile. It is test infrastructure, not a replacement hosted Gather product or a user-facing preview.

On a permitted native-extension runner:

```sh
GATHER_CHROMIUM_PATH=/path/to/chromium node tests/browser-acceptance.mjs
```

`browser-journey.mjs` forwards to this sandbox-enabled entry point. Native Chrome versions may require their supported unpacked-extension testing workflow rather than old load-extension switches. Inspect failures; do not count a launch/zero-worker run as passed.

## Native acceptance still required

1. Install the actual `account-id-tool` in isolated Chrome and Edge profiles. Confirm quick copy with no project and exact long IDs. Inspect keyboard focus, native popup height, actual side-panel opening and zoom.
2. Repeat Northbridge/Alex → search → result → visible/selection capture while another Gather view switches to Southridge. Verify actual opener availability, explicit reassignment/detachment and shown destinations. No opener means an honest default, not guessed linkage.
3. Invoke toolbar/context menu to grant activeTab; navigate cross-origin and test access guidance. Switch source tabs or navigate during full-page capture and verify no other tab's pixels are retained.
4. Exercise full page on controlled sticky/lazy/infinite/nested fixtures, high DPI, browser zoom, resource limits and cancellation/controller closure. Inspect seams and partial labels. Wait for page-side restoration after abrupt closure.
5. Enable Downloads export, interrupt/deny a native download, retry, inspect safe relative filenames/JSON pairs and separate saved/export states. Custom directory permission is not shipped.
6. Suspend/restart the worker, close/reopen browser and extension pages, back up and restore into another isolated **installation**, and verify binary images and exact relationships. Current rendered tests use separate browser-origin storage, not two installed extensions.

No performance advantage, live success rate, comprehensive platform audit, store readiness or production readiness is claimed.

# Gather 1.8.13 engineering notes

The 1.8.12 checkpoint is preserved; no schema number, permission or runtime dependency changed. Runtime has 81 files, including the new pure capture-crop geometry helper. Published ZIPs are immutable.

- core.jsonObjects now loops every known assignment per script. Account binding, exact strings and conflict rejection remain; generated isolated-world reader is rebuilt and checked. This confirmed bug is distinct from the unverified signed-in Edge report.
- Selection HUD is edge-positioned. Passive text passes pointer events; controls retain keyboard access. Drag hides it and cleanup removes it before acquisition. exactSelectionBounds refuses clipping for live captures; editor selectionBounds retains deliberate clamping. Aspect tolerance is checked in bitmap pixels.
- Word-style crop is a temporary rectangle over the unchanged current canvas. Eight handles/move/keyboard operations map CSS positions to image pixels. Apply appends a normal crop operation; Cancel leaves pixels unchanged. Save/Copy are disabled during pending crop. Stale/deleted-image guards remain.
- Recent batches are ordered by creation time, limited to five and pruned atomically with archive/quick-pointer cleanup. Null tombstones contain no account content and prevent stale writer resurrection. Restore enforces retention inside its existing history lock/journal, without a nested lock. Saved case observations remain independent.
- New filing cases use prepareFilingCase and the existing binary import/workspace journal to commit case/scan/SOC structure. They persist locally with an automatic scan and stable SOC IDs, without seeds, queue or coverage creation. Existing ephemeral/local research cases and old backups still validate. SOCs created together sort deterministically by creation time, role number and stable ID; database UUID order never determines the selector order. Compatibility APIs remain; ordinary intake creation UI was removed.
- Toolbar filing remains frozen. Source URL follows navigation within the same tab; case/global destination changes do not replace the displayed assignment. Case/SOC capture filters change only browsing state. Internal scan selectors stay available for legacy multiple-scan cases.
- Popup opens the current profile lookup only on the explicit toolbar invocation, preserving staged drafts. Pasted batches remain an expansion. Auto-copy IDs ignores the manual copy-format selection. One selection button obeys screenshot auto-copy. Copy receives focus when lookup completes; the main screenshot action stays visible after a single resolved profile.

Validation layers and outstanding native Edge gates are in TESTING and R4-WORKFLOW-RECONCILIATION. No static source pattern or fictional test is a legal/security guarantee. Previous details are archived under docs/history/1.8.12-BUILD-NOTES.md.

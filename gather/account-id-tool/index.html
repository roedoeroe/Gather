      Paste. Find. Copy.

      Each result keeps the display name, your original link, and user ID together. Missing names stay marked as unavailable. Imported names are marked as supplied until checked.

      Account details keeps the account, supplied ID, and notes together. Message headers, timestamps, and unrelated text are ignored. IDs immediately after a link stay with that account; ambiguous numbers are listed for review.

      Use Display names beside Account details to show or omit the name line in the preview, copied text, and text downloads. Names stay saved with the batch. This choice is remembered and shared with the toolbar panel.

      From the toolbar panel, Run on this page grabs your current profile link and starts immediately. It reads the open page first and follows your Auto-copy setting. The button is greyed out on non-profile pages or while a page is loading.

      Clear profile data adds (PRIV) or (EMPTY) beside the link. EMPTY means an explicit zero public-post or upload count. Private, hidden, or unavailable content is never assumed empty. POSS is always yours; an existing POSS combines as (POSS/PRIV) or (POSS/EMPTY).

      Notes lets you edit your annotations or turn off automatic status for an account. Changes to an older PRIV/EMPTY note are shown, and the original note stays in the saved record. If the site provides no clear evidence, supplied status remains marked as unverified.

      Supplied IDs are checked against the profile. Mismatches show both IDs; choose Use found ID to accept a correction. IDs only excludes unchecked or conflicting supplied IDs and removes repeated IDs within each platform. A saved check reflects its lookup time; use Recheck for a fresh check.

# Security and private reports

Gather's GitHub repository is public. Use fictional reproductions for public bug reports. Do not attach real case data, school/student/contact details, profile URLs or IDs, screenshots of investigations, page source, cookies, tokens, clipboard contents, organization packs or Gather backups.

For sensitive findings, use an established private channel with the maintainer or your organization's security contact before sharing details. This repository does not currently have GitHub private vulnerability reporting enabled; do not treat a public issue as a private inbox.

Gather has no case-data cloud service, telemetry or automatic support upload. Deliberate platform/search requests still contact external services. Local storage and backups are not encrypted by Gather, and deletion cannot remove files or history outside the extension.

# Gather 1.8.19 RC

Get real post date and Copy date provide post-bound publication metadata with explicit timezone and precision. Ordinary Facebook posts/photos, TikTok photos and X status URLs now enter the existing bound-author lookup. Instagram posts use the existing conditional two-second metadata buffer. Permissions and storage schemas are unchanged.

Install only Gather-1.8.19-extension.zip. Extract into a permanent folder and Load unpacked → account-id-tool in edge://extensions. To update, finish captures, close Gather windows, replace files in the same installed folder and click Reload. Confirm 1.8.19. Do not uninstall or clear storage. Keep 1.8.18 and a matching private backup for rollback testing in a separate browser profile; Reference has a separate export.

Dates and author IDs depend on available metadata; supported URLs are not a promise of extraction. X needs current-page toolbar invocation. Relative dates and ambiguous authors are never guessed. Date results are temporary. No new background data collection or cloud storage is introduced.

See TESTING.md for current evidence. Native Linux Edge uses fictional HTTPS responses; signed-in live sites, Windows scaling and native OS dialogs are not certified. Previous release evidence remains historical.
